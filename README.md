# 介護福祉士 キソマナ 国家試験対策アプリ

1テーマの重要用語を1画面にカードで並べ、繰り返し見て覚える介護福祉士国家試験の学習アプリです。総合問題を除く12科目・500語を収録しています。

- **基礎学習**：説明文と覚えるポイントの重要語（制度・給付・機関・職種の名前、健側⇄患側などひっかけになる語、数値、「医療職に任せる」などの行動、してはいけないこと）を赤字で表示する。「カードで覚える」（用語から意味を思い出す）と「説明つきで読む」（全体を通読する）を切り替えて使う
- **マイ教科書**：基礎学習で選んだ用語だけを、基礎学習と同じ科目・テーマ・ページの形で見返せる。カードで覚えるでは確認画面の「マイ教科書に追加」、説明つきで読むでは用語を右にスライドして出るピンから追加・削除する
- **基礎問題**：同じ用語データから5択問題を自動で作る。「用語→説明」「説明→用語」「ミックス」の3形式。正解と一語だけ違う「ひっかけ」の説明（健側⇄患側、上顎⇄下顎、市町村⇄都道府県、数字など）や、名前の似た用語を選択肢に混ぜ、2択で迷う問題にする
- **過去問題**：2種類を切り替えて使う
  - 年度別（本試験）：第34〜38回。問題は試験センター公式サイトのPDF（第36回以降）、または公開終了した第34・35回は掲載ページで読み、アプリのマークシートで答えを選ぶと採点・合格基準（合格点＋11科目群すべてで得点）の判定ができる。正答は試験センター／厚生労働省の公表値（`src/data/pastExams.js`）。試験問題そのものは著作物のため収録していない
  - 年度別の解答画面の「解説を見る」で、その科目の全問の解説（正答の要旨と、間違えやすい選択肢やポイント）を1画面で読める（`src/data/pastExplain.js`。問題文は収録せず、独自の言葉でまとめたもの）
  - オリジナル問題：本試験と同じ13科目・125問の構成（尊厳と自立2問…総合問題12問）で出題。手作りの問題（`src/data/exams.js`）と、カードから自動で作る「正しいものを1つ選びなさい」形式の問題を使う。正解した問題は次から新しい問題に入れ替わり、まちがえた問題は正解するまで残る。科目の問題をすべて正解したら最初に戻るので、終わりなく練習できる
- **過去に間違えた問題**：基礎問題で間違えた用語が科目・テーマごとに集まり、テーマ・科目・全体の単位で解き直せる。「まだ正解していない」（最後に間違えたもの。正解すると外れる）と「一度でも間違えた」を切り替えられる
- **苦手傾向分析**：解答記録（10問以上）から、傾向のコメント、重点的に勉強するテーマ（正答率の低い順に3つ）、科目別・出題形式別の正答率、繰り返し間違えている用語を自動でまとめる

- **設定・このアプリについて**：学習記録の書き出し（ファイル保存・コピー）と読み込み（ファイル・貼り付け）、プライバシーポリシー・利用規約・お問い合わせへのリンク

## ふりがな
画面右上の「ふりがな」ボタンで、漢字にふりがなを付ける（設定は端末に保存）。
- 辞書：`src/data/furigana.js`（表記 → `漢字{よみ}かな`。`#` で始まるキーは数字のあとの読み）
- 作り方：アプリ内の文章を形態素解析（kuromoji）で読みに分け、介護の専門用語は手で直した一覧で上書きして自動生成する
- 文章を追加したら辞書も作り直す。辞書にない漢字は、ふりがななしで表示される
- コピーしたときは、ふりがなを外して漢字だけにする

## 有料機能・広告（ストアのアプリ版）
- オリジナル問題は有料（買い切り・商品ID `originals_unlock`）。未購入でも20問まで無料で試せる（`FREE_TRIAL`）。お試しの残りがなくなると購入画面を表示する。Web版にも同じ制限がかかり、購入はストアのアプリ版でのみできる
- 広告の非表示も買い切り（商品ID `remove_ads`）
- 広告は学習の途中では出さず、区切りの画面（問題の結果・テーマの完了・過去問の採点）でだけ、前回の広告から5分以上たっていれば表示する。起動から5分間は出さない（`app.js` の `maybeShowAd`）
- 広告の表示・購入はアプリ側が `window.KaigoNative` として用意する（`showInterstitial()`、`purchase(productId)`、`restorePurchases()`（購入済みの商品IDの配列を返す）、任意で `price(productId)`・`saveFile(name, text)`）。Web版ではこれがないため広告は出ず、購入もできない
- 買い切りで購入すると `adFree` が保存され、広告が表示されなくなる

## 動かし方
- `index.html` をブラウザで開く（ビルド不要・依存ライブラリなし）
- `node build.mjs` で次の2つを作る
  - `dist/kaigo-study.html`：1ファイル版（アーティファクト・確認用）
  - `dist/app/`：ホーム画面に追加できるアプリ版（PWA）。フォルダごと Web に公開して使う

## アプリ版（PWA）の公開
### GitHub Pages（おすすめ・無料）
1. GitHub で新しいリポジトリを作る（Public）
2. このフォルダの中身をすべてアップロードする（`docs/` フォルダを含める）
3. リポジトリの Settings → Pages → Build and deployment で、Source を「Deploy from a branch」、Branch を「main」「/docs」にして Save
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で公開される。スマホで開いてホーム画面に追加する

### 更新するとき
1. 教材や画面を直したら、`pwa/sw.js` の `VERSION` を上げてから `node build.mjs` を実行する（`docs/` が更新される）
2. 変更をリポジトリに反映する。数分後、アプリを開き直すと最新版に切り替わる

### その他
- Netlify Drop（https://app.netlify.com/drop）に `dist/app/` をドロップしても公開できる
- アイコン・マニフェスト・オフライン用の Service Worker は `pwa/` にある

## 収録方針
- 介護福祉士国家試験に**出る・出やすい内容だけ**を入れる。教科書に載っていても、出ない／ほぼ出ないものは入れない
- 人物は出題の多い人に絞る。その他の人名は手法カードの「提唱者」欄で扱う
- 1ページはスマホ1画面に収まる8語までを上限とする
- 頻出事項は「覚えるポイント」欄に埋めず、1枚のカードにする。試験で問われる場面のテーマに置く（例：ヒートショックは入浴）

## 収録の確認方法
- 教材は、直近5回分の本試験（第34〜38回・625問）の出題テーマを1問ずつ洗い出し、全カードと突き合わせて確認している
- 知識で答える問題のテーマは、カードまたは「覚えるポイント」に入っていること。事例の判断問題は、その判断の根拠になる原則が入っていること
- 新しい回の試験が公開されたら、同じ方法でその回の全問を照合し、足りないテーマを追加する

## 教材の追加
科目ファイルのテーマ・ページに用語を足すだけで、基礎学習と基礎問題の両方に反映されます。

```js
// 短縮形（配列）
["用語", "よみ・正式名称", "説明", "覚えるポイント", { person: "提唱者" }]

// オブジェクト形式
{ term: "用語", reading: "", definition: "説明", point: "", person: "", profile: "", example: "" }
```
- `term` と `definition` 以外は任意
- 用語のIDは「テーマID.用語」で自動生成される。公開後に用語名を変えると、その用語の学習記録は引き継がれない
- 基礎問題の誤答の選択肢は、同じテーマ → 同じ科目の順に自動で選ばれる

## 拡張の方針
- **過去問題の追加**：`exams.js` の各科目の配列の末尾に問題を足す（問題IDは順番で決まるため、途中に挿入しない）。`terms` に関連する用語名を書くと、解説に表示される
- **ひっかけの語を増やす**：`app.js` の `SWAP_PAIRS` に入れ替える語の組を足す
- **サーバー保存**：画面は `KaigoStore` のAPIだけを使っているため、`store.js` の中身をAPI通信に置き換えれば移行できる

## 年度別の本試験を追加するとき
`pastExams.js` の `years` の先頭に、新しい回を追加する（回・実施日・合格点・科目ごとの問題番号の範囲と公式PDFのURL・125問の正答）。正答は必ず試験センター／厚生労働省の公表値を使い、複数正答は配列で書く。試験センターで問題の公開が終わった回は、科目の `pdf` を省き、年度に `read: { url, label }`（問題を読めるページ）を書く。
