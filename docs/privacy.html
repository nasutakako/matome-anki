プライバシーポリシー

見て覚える 介護福祉士 国家試験対策　制定日：2026年11月3日

「見て覚える 介護福祉士 国家試験対策」（以下「本アプリ」）の提供者（以下「提供者」）は、利用者の情報を次のとおり取り扱います。

1. 本アプリが扱う情報

  • 学習記録：確認済みのカード、解答の正誤、過去問題の解答、表示の設定などです。これらは利用者の端末の中（ブラウザまたはアプリの保存領域）にだけ保存され、提供者のサーバーには送信されません。
  • アカウント：本アプリには会員登録やログインの機能はなく、氏名・メールアドレスなどの個人情報を入力する場面はありません。
  • 学習記録のバックアップ：利用者が「書き出す」を選んだときだけ、学習記録をファイルやテキストとして端末に保存します。保存先の管理は利用者が行います。

2. 広告について

ストアで配信するアプリ版では、Google LLC が提供する広告配信サービス「Google AdMob」を利用して広告を表示する場合があります。AdMob は、広告の配信・効果測定・不正防止のために、広告識別子（IDFA・広告ID）、端末やOSの種類、おおよその位置情報（IPアドレスから推定）、広告の表示・タップの状況などを収集・利用することがあります。

  • 収集される情報と利用目的の詳細は、Google の広告に関するポリシーおよびGoogle プライバシーポリシーをご確認ください。
  • iPhone では、トラッキングの許可を求める画面で「許可しない」を選ぶと、広告識別子は利用されません。Android では、端末の設定で広告IDの削除やリセットができます。
  • パーソナライズされていない広告を表示する場合も、広告の配信と不正防止のために一部の情報が利用されます。

3. アプリ内課金（広告の非表示）

広告を非表示にする買い切りの購入は、App Store または Google Play の決済の仕組みで行われます。支払い情報は Apple または Google が管理し、提供者が受け取ることはありません。提供者が確認するのは、購入が完了したかどうかだけです。

4. Web版について

Web版は GitHub Pages（GitHub, Inc.）で公開しています。ページの配信にあたり、GitHub がアクセスログ（IPアドレスなど）を記録することがあります。詳しくは GitHub のプライバシーに関する声明をご確認ください。Web版には広告を表示していません。

5. 第三者への提供

提供者は、利用者の個人情報を取得しないため、第三者に提供することはありません。広告配信事業者による情報の取り扱いは、上記2のとおりです。

6. 子どもの利用

本アプリは介護福祉士国家試験の受験者を対象としており、13歳未満の子どもを対象としたものではありません。

7. 改定

本ポリシーは、必要に応じて改定することがあります。改定した場合は、このページで公開します。

8. お問い合わせ

本ポリシーに関するお問い合わせは、お問い合わせのページからご連絡ください。
